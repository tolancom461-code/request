# Phase 2B C1 Contract Requirements

| Requirement group | Enforced interpretation |
|---|---|
| Presentation only | Build isolated evidence and choice artifacts only; do not begin Phase 2C or change product behavior. |
| Real template claim | T1/T2/T3 must import and visibly render genuine library components. |
| Neutral comparison | Templates use one common identity/content/skeleton; only library primitives determine visual differences. |
| Independent identity | I1/I2/I3 use a common skeleton with separate identity tokens and no T# binding. |
| Screenshots | Supply desktop, quantity/unit popup, representative tablet surface, and identity screenshots grouped by ID. |
| Choice sheet | Leave T# and I# blank; do not recommend or select a winner. |
| Isolation | Candidate dependencies remain in a dedicated workspace with a separate manifest/lockfile. |
| Evidence | Record package versions, source imports, mapping, RTL setup, adapters, risks, licenses, build/run and visual verification. |
