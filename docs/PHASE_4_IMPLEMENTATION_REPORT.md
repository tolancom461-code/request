## الفحص المرئي وبيانات التحقق

فُحص جدول عنصر مفلتر ونموذج إدارته بالعربية، مع وحدة أساس ومعامل تحويل ووحدة ثانوية، وتكوين فرع، وعلاقة مورد أساسي. وفُحص الجدول نفسه بالإنجليزية LTR والأردية RTL. استخدم الفحص حساب System Admin وسجل عنصر مؤقتين فقط؛ حذف الحساب والجلسات والعنصر والفئة والوحدات والفرع والمورد والعلاقات بعد الالتقاط.

تظهر قاعدة تحقق TiDB القديمة بعض سجلات `TEST-*` التاريخية الناتجة عن اختبارات التكامل السابقة عند عدم تطبيق الفلتر. لا توجد هذه السجلات داخل مكونات الواجهة أو الـseed أو الحزمة كبيانات أعمال؛ استُخدم فلتر `P4V-SKU-*` في لقطات Phase 4 لتجنب تقديمها على أنها بيانات مطعم فعلية.
