# Client Source Delivery Manifest

هذه الحزمة تتضمن كود المصدر الكامل للمشروع، ومجلدات التطبيقات، وحزم المشاركة، وPrisma، والاختبارات، والنصوص، وملفات البناء القابلة لإعادة الإنتاج مثل `package.json` و`pnpm-lock.yaml`. لا تتضمن الأدلة والتقارير التاريخية أو لقطات التحقق؛ فهي ليست مطلوبة لتشغيل الكود وقد تتضمن مراجع تشغيلية قديمة.

لا تتضمن الحزمة أي قيمة سرية أو بيانات اعتماد. استبعدت عمدًا ملفات البيئة (`.env*`)، وتهيئة المشروع المحمية، واعتمادات Node المحلية، ومخرجات البناء، وسجل Git، وسجلات التشغيل، وأي نواتج اختبار/تغليف محلية. بعد فك الضغط، استخدم `pnpm install --frozen-lockfile` ثم أضف الأسرار المناسبة في بيئتك قبل التشغيل.
